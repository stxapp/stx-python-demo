# Pip-installable pin for the demo scripts.
#
# Run:
#     pip install -r requirements.txt
#
# stx-python is in pre-release on TestPyPI until 1.0:
#   --index-url + --extra-index-url tell pip to look on TestPyPI for
#     the SDK while still resolving transitive deps from main PyPI.
#   --pre enables alpha/beta resolution (without it, `stx-python`
#     wouldn't resolve to anything since 1.0 isn't out yet).
#
# Once we ship 1.0 to main PyPI, this whole file collapses to:
#     stx-python
--index-url https://test.pypi.org/simple/
--extra-index-url https://pypi.org/simple/
--pre

stx-python
